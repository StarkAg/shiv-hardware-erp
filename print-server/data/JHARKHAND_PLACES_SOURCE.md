# Jharkhand Place Dictionary

Derived from `dropdevrahul/pincodes-india` `pincode.csv`, filtered to `StateName = JHARKHAND` and reduced to unique place names from office, district, and division fields.

Source: https://github.com/dropdevrahul/pincodes-india
License: MIT
Original project notes that data is collected from the official Data.gov.in All India Pincode Directory API.
