# IndicNames-1.5M — Indian Names Dataset

A large-scale curated dataset of **1.5 million unique Indian names** collected from multiple Indic languages and regions.

Suitable for:
- Name generation (LLMs / GPT fine-tuning)
- NLP experimentation with Indian names data
- Tokenization / language model benchmarking
